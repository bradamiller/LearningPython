## The mission

Your robot must:

1. Follow the taped circle with `track_to_intersection()`.
2. Detect the cross intersection.
3. Reverse direction.
4. Keep following, and repeat for **4 total reversals**.
5. Stop and print a completion message.

## Build it in pieces

You have every part already: the sensor toolkit from Lesson 2-8, the driving toolkit
from Lesson 2-9, and the reversal trick you worked out above. What's left is assembling them and
tuning — which is most of what real robot work is.

Build in this order, testing each before adding the next:

1. `track_to_intersection()` then `drive_past_intersection()` — does it stop with the wheels on the cross?
2. One `turn_clockwise()` — does it find the line again?
3. One full reversal — two clockwise turns, then following back the other way.
4. The loop that does it four times.

<TeacherNote title="Reference program (teacher copy)">

The whole thing: both toolkits plus a main program that reverses four times (two
clockwise sensor-ended turns make a 180° reversal on the line). Use it to unstick a
team, not as a handout — the assembly and tuning is the graded work. The file is
`lesson-10-final-project.py` in the Module 2 solutions; the class version is
`lesson-10-final-project-class-addon.py`.

```python
from XRPLib.reflectance import Reflectance
from XRPLib.differential_drive import DifferentialDrive
from XRPLib.board import Board

# ===== Sensor toolkit (Lesson 2-8) =====
reflectance = Reflectance.get_default_reflectance()
THRESHOLD = 0.5

def get_left():
    return reflectance.get_left()

def get_right():
    return reflectance.get_right()

def get_error():
    return get_left() - get_right()

def is_at_cross():
    return get_left() > THRESHOLD and get_right() > THRESHOLD

def is_either_on_line():
    return get_left() > THRESHOLD or get_right() > THRESHOLD

# ===== Driving toolkit (Lesson 2-9) =====
drivetrain = DifferentialDrive.get_default_differential_drive()
BASE_EFFORT = 0.4
KP = 0.5
TURN_EFFORT = 0.25

def drive_past_intersection():
    drivetrain.straight(8.75, 0.5)

def track_to_intersection():
    while not is_at_cross():
        error = get_error()
        correction = error * KP
        drivetrain.arcade(BASE_EFFORT, -correction)
    drivetrain.stop()

def turn_clockwise():
    drivetrain.turn(-60, TURN_EFFORT)
    drivetrain.arcade(0, -TURN_EFFORT)
    while not is_either_on_line():
        pass
    drivetrain.stop()

def turn_counterclockwise():
    drivetrain.turn(60, TURN_EFFORT)
    drivetrain.arcade(0, TURN_EFFORT)
    while not is_either_on_line():
        pass
    drivetrain.stop()

# ===== MAIN PROGRAM =====
board = Board.get_default_board()

board.wait_for_button()
print("Module 2 Final Project -- starting!")

for i in range(4):
    print("Leg", i + 1, "-- following line to the cross...")
    track_to_intersection()
    drive_past_intersection()
    print("Cross detected! Reversing...")
    turn_clockwise()
    turn_clockwise()      # two sensor-ended turns = 180 deg reversal

print("Complete! 4 reversals done.")
```

</TeacherNote>

<TeacherNote title="Run it as a build, and test in pieces">

Treat this as a multi-day arc: plan → build → test → present. Insist on **incremental
testing** — `track_to_intersection()` alone, then one turn, then one full reversal,
then the four-rep loop. The common fixes are all *tuning*: `THRESHOLD` (cross not
detected), the blind part of the turn or `TURN_EFFORT` (the loop ends on the old line,
or spins past the new one), and `BASE_EFFORT` (overshoots the cross) — frame that
tuning as the real engineering, not failure. Two successful
reversals already demonstrate mastery; four is the goal.

</TeacherNote>

## Activity · Test, tune, present

Work up in stages, and keep a note of what you tuned:

1. Does `track_to_intersection()` follow and stop at the cross, with `drive_past_intersection()` leaving the wheels on it?
2. Does one turn-around find the line again?
3. Does one full reversal work end to end?
4. Do all four reversals run and stop?

Then demo it and reflect: what was hardest, how did the toolkits make the project
easier, and what would you add with more time?

Look back at the journey: you started Module 2 reading a single sensor value, and
you're finishing it with two cooperating toolkits that follow a line, detect
intersections, and navigate a course. That design — sensing and driving cleanly
separated, each built on the layer below — is exactly how professional robot code is
structured, and you'll build directly on it next. (If you did the class extensions,
you have the same thing as `LineSensor` and `LineTrack` objects.)
