<TeacherBanner>
Teacher mode is on: the sample programs on this page are yours only. Flip the switch
(bottom-right) to preview what students see.
</TeacherBanner>

This page holds a complete, working program for each module, for checking student
work and for getting a robot running when you need one in a hurry. The programs
are shown only in teacher mode. Students: the [robot.py templates](/templates) are
the files for you.

<TeacherNote title="How to use these">

Each module has its complete program as a single file. From Module 2 on that file
is `robot.py` as it stands at the end of the module, on the function track and on
the class track. Module 1's programs are separate files, one per project, because
students start `robot.py` in Lesson 2-1.

A student's file won't match these line for line, and doesn't need to. A version
that works differently and passes the lesson's tests is right. Use these to find
where a student's version goes wrong, not as the answer it must look like.

For any single lesson, the **Solution (teacher copy)** note at the end of the
lesson's activity has that lesson's code.

</TeacherNote>
