## Teacher mode

The switch in the bottom-right corner of every page turns on **teacher mode**. It
asks for the teacher password, and once it is on, every page shows its teacher
notes: timing, setup tips, common bugs, differentiation, assessment, and the
complete code for each activity in a note titled **Solution (teacher copy)**.
Turning it off locks it again, so a shared classroom computer doesn't stay
unlocked. Teacher mode also shows the answer-key link next to each lesson's
printable knowledge check.

Teacher mode is a speed bump, not a vault. It keeps answers off a student's screen
while they work, and it keeps them out of anything printed from student view, but
the site is a set of static pages and a determined student can find what's in
them. Grade the work you saw being done, and ask students to explain their code;
that is the check that can't be looked up.

The password isn't posted on the site. Teachers get it from the course author; if
a colleague needs it, point them there rather than forwarding it in a group message
or putting it on a slide.

## What each lesson gives you

Every lesson page has the same parts, in the same places:

- **A header** with a time estimate and, where one exists, a **Slides
  (PowerPoint)** link. The decks follow the page section by section, use its
  figures, keep the teaching notes in the speaker notes, and never show a
  solution.
- **Objectives**, then a **printable knowledge check** link: a handout version of
  the lesson's questions, with an answer key you can see in teacher mode. The full
  set is under [Printable Checks](/checks).
- **Activities**, each headed `Activity · …`. These are what students do and hand
  in, and they are what the [pacing guide](/pacing) counts.
- **Knowledge checks** through the page: interactive multiple-choice questions
  that give feedback on the spot.
- **Check your work** boxes: closed until a student opens them, holding a worked
  result to compare against *after* trying. They don't print.
- **Teacher notes**: the gray boxes, teacher mode only.
- **Optional extensions** in some lessons from Module 2 on: the class version of
  code the student has just written as functions. See
  [Course design](/teacher-guide/course-design#d1-functions-are-the-spine-classes-are-a-per-student-extension).

From Lesson 2-1 on, students keep one program file, `robot.py`, that grows a
section per lesson. The [robot.py templates](/templates) page has that file, with
outlines but no answers, as it stands after every lesson, which is how a student
who missed a week or lost a file gets back on track.
