## Lesson 4-2 · Tuples

<TeacherNote title="4-2 Try it: five positions and two distances">

Scratch work: none of this goes into `robot.py`. Any five positions are fine; keep
each destination up and to the right of its start, as the lesson's teacher note
says, until Lesson 4-4 deals with negative distances.

```python title="lesson_4_2_tuples.py"
# Five grid positions, one tuple each
home = (0, 0)
school = (2, 3)
library = (3, 1)
park = (1, 2)
store = (3, 3)

print("home: x =", home[0], " y =", home[1])
print("school: x =", school[0], " y =", school[1])
print("library: x =", library[0], " y =", library[1])
print("park: x =", park[0], " y =", park[1])
print("store: x =", store[0], " y =", store[1])

# Two distances, each destination up and to the right of its start
x_distance = school[0] - home[0]          # 2
y_distance = school[1] - home[1]          # 3
print("home to school:", x_distance + y_distance, "steps")    # 5

x_distance = store[0] - park[0]           # 2
y_distance = store[1] - park[1]           # 1
print("park to store:", x_distance + y_distance, "steps")     # 3
```

</TeacherNote>
