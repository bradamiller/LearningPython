## Lesson 4-2 · Tuples

<TeacherNote title="4-2 Try it: compute_distance() and five calls">

Scratch work: none of this goes into `robot.py`. The five calls are the ones the
lesson gives as its test; each `destination` is up and to the right of its `start`, so
nothing comes out negative until Lesson 4-4 deals with that. The lesson shows the
output this prints, so students write only the function and check it against that.

```python title="lesson_4_2_tuples.py"
def compute_distance(start, destination):
    print("From", start, "to", destination)
    x_distance = destination[0] - start[0]
    y_distance = destination[1] - start[1]
    print("Manhattan distance:", x_distance + y_distance)


compute_distance((0, 0), (2, 3))     # 5
compute_distance((1, 1), (3, 2))     # 3
compute_distance((0, 0), (3, 3))     # 6
compute_distance((2, 0), (2, 3))     # 3
compute_distance((0, 2), (1, 3))     # 2
```

</TeacherNote>
