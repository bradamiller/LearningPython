## Lesson 1-10 · Python Loops

<TeacherNote title="1-10 step 2: six squares">

Step 1's predictions are in the student reveal (440 cm, 16 turns). For step 2 the

```python title="lesson_1_10_six_squares.py"

board.wait_for_button()

        drivetrain.straight(size)
        drivetrain.turn(90)
```

## Lesson 1-11 · Python Functions

<TeacherNote title="1-11 Build a shape library: all three steps">

`polygon()` is written once, in its step 3 form: with the default, `polygon(6)`
draws 30 cm sides and `polygon(6, 50)` still draws 50 cm sides. A student who
stopped at step 2 has the same function without `=30`. The perimeters print 90,
100 and 100.

```python title="lesson_1_11_shape_library.py"
from XRPLib.differential_drive import DifferentialDrive
from XRPLib.board import Board

drivetrain = DifferentialDrive.get_default_differential_drive()
board = Board.get_default_board()

def calculate_angle(sides):
    """Return the exterior angle of a regular polygon."""
    return 360 / sides

def calculate_perimeter(sides, side_length):
    """Return the distance around a regular polygon."""
    return sides * side_length

def polygon(sides, side_length=30):
    """Draw a regular polygon."""
    angle = calculate_angle(sides)
    for i in range(sides):
        drivetrain.straight(side_length)
        drivetrain.turn(angle)

board.wait_for_button()

# Steps 1 and 2: three shapes, each followed by its perimeter
polygon(3, 30)
print("Triangle perimeter:", calculate_perimeter(3, 30))     # 90
polygon(4, 25)
print("Square perimeter:", calculate_perimeter(4, 25))       # 100
polygon(5, 20)
print("Pentagon perimeter:", calculate_perimeter(5, 20))     # 100

# Step 3 (challenge): the default side_length
polygon(6)          # hexagon, 30 cm sides
polygon(6, 50)      # the argument still wins: 50 cm sides
```

</TeacherNote>

<TeacherNote title="1-12 Option A sample: Polygon artist">

A triangle through an octagon in a row, then a star. The star turns 144 degrees
at each point, so it goes round twice (5 × 144 = 720): a good question to ask a
team that tries 72 and gets a pentagon.

```python title="lesson_1_12_polygon_artist.py"
"""
Module 1 Final Project: Polygon Artist (sample)
Team: teacher sample
Description: Draws a row of shapes that grow from a triangle to an
octagon, then a five-pointed star, using one polygon function.
"""

from XRPLib.differential_drive import DifferentialDrive
from XRPLib.board import Board
import time

drivetrain = DifferentialDrive.get_default_differential_drive()
board = Board.get_default_board()

# ===== HELPER FUNCTIONS =====
def calculate_angle(sides):
    """Return the exterior angle of a regular polygon."""
    return 360 / sides

def move_over(distance):
    """Drive to the start of the next shape without drawing it."""
    drivetrain.straight(distance)
    time.sleep(0.5)

# ===== MAIN FUNCTIONS =====
def polygon(sides, side_length):
    """Draw one regular polygon."""
    angle = calculate_angle(sides)
    for i in range(sides):
        drivetrain.straight(side_length)
        drivetrain.turn(angle)

def star(side_length):
    """Draw a five-pointed star: five sides, turning 144 degrees."""
    for i in range(5):
        drivetrain.straight(side_length)
        drivetrain.turn(144)       # 720 / 5: a star goes round twice

def gallery(side_length):
    """Draw a triangle through an octagon, moving over between them."""
    for sides in range(3, 9):
        print("Drawing a", sides, "sided shape")
        polygon(sides, side_length)
        move_over(3 * side_length)     # an octagon is about 2.4 sides wide

# ===== RUN =====
board.wait_for_button()

print("Starting...")
gallery(15)
print("And a star")
star(30)
print("Done!")
```

</TeacherNote>

<TeacherNote title="1-12 Option B sample: Precision navigation">

A rectangular delivery route with three stops, built on
`navigate_segment(distance, angle)` from the lesson's function inventory. The leg
lengths are settings at the top, because they're the numbers a team measures and
changes.

```python title="lesson_1_12_precision_navigation.py"
"""
Module 1 Final Project: Precision Navigation (sample)
Team: teacher sample
Description: A delivery robot that drives a rectangular route, stops at
three drop-off points, and returns to where it started.
"""

from XRPLib.differential_drive import DifferentialDrive
from XRPLib.board import Board
import time

drivetrain = DifferentialDrive.get_default_differential_drive()
board = Board.get_default_board()

# Measured on our floor: change these to fit your course.
LONG_LEG = 60
SHORT_LEG = 40

# ===== HELPER FUNCTIONS =====
def navigate_segment(distance, angle):
    """Drive one leg of the route, then turn to face the next leg."""
    print("Leg:", distance, "cm, then turn", angle)
    drivetrain.straight(distance)
    drivetrain.turn(angle)

def deliver(stop_name):
    """Pause at a drop-off point so everyone can see it arrive."""
    print("Delivered to", stop_name)
    time.sleep(2)

# ===== MAIN FUNCTIONS =====
def delivery_route():
    """Visit the three stops in order and return to the start."""
    navigate_segment(LONG_LEG, 90)
    deliver("Stop A")
    navigate_segment(SHORT_LEG, 90)
    deliver("Stop B")
    navigate_segment(LONG_LEG, 90)
    deliver("Stop C")
    navigate_segment(SHORT_LEG, 90)     # home, facing the way it began
    print("Home")

# ===== RUN =====
board.wait_for_button()

print("Starting delivery run...")
delivery_route()
print("Done!")
```

</TeacherNote>
