To tell the robot *where to go*, you need a way to name every spot on the grid. This
lesson builds that system — **(row, column) coordinates** — with paper and the
physical grid, no code yet. A solid mental model here makes tuples, lists, and the
Manhattan algorithm click later.

<Objectives>

By the end of this lesson you will be able to:

- Explain what a coordinate system is and why a robot needs one
- Name any intersection with a `(row, column)` pair
- Tell row (down) from column (right), and remember order matters
- Count the steps between two positions (the Manhattan distance)

</Objectives>

## Two numbers name any spot

You already know coordinate systems: Battleship ("B4"), chess ("e5"), a spreadsheet
cell ("A1"), GPS latitude and longitude. Two numbers are enough to pinpoint any spot
on a flat surface. Our grid uses the convention **(row, column)**:

- The **row** (first number) is how far *down* from the top — the top row is row `0`.
- The **column** (second number) is how far *right* from the left — the left column is column `0`.

<Figure
  placeholderLabel="Labeled 4×4 grid: every intersection marked with its (row, col), top-left = (0,0)"
  caption="Row first, column second. Top-left is (0, 0) — we count from zero."
/>

Two things to burn in: we **count from zero** (the top-left is `(0, 0)`, not
`(1, 1)`), and **order matters** — `(2, 3)` and `(3, 2)` are *different* spots.

## Counting steps: Manhattan distance

Since the robot follows lines (no diagonals), the distance between two spots is just
the row steps plus the column steps:

> steps = (row difference) + (column difference)

From `(0, 0)` to `(2, 3)`: 2 rows down + 3 columns right = **5 steps**. This "blocks
you'd walk" total is called the **Manhattan distance** — named for walking a city
grid where you can't cut through buildings.

<KnowledgeCheck
  question="How many steps from (0, 0) to (3, 2), moving only along grid lines?"
  options={[
    {text: '5', correct: true},
    {text: '6'},
    {text: '1'},
    {text: '3'},
  ]}
  explanation="3 rows down + 2 columns right = 5 steps. That sum is the Manhattan distance."
/>

<TeacherNote title="Row/column order is the #1 stumble">

Repeat the convention constantly — "row first, column second; row is down, column is
right" — and consider posting it. Zero-indexing is also new for most: they count from
1 by habit, so name *why* (Python indexes from 0, and matching now avoids pain
later). If you can, have students physically **walk the grid** and call out their
coordinates — kinesthetic beats diagrams here. Keep it code-free; when they ask "when
do we code?", answer "next lesson — today you're building the map the code will use."

</TeacherNote>

## Activity · Map it

Grab a blank grid and label every intersection with its `(row, col)`. Check yourself:
the bottom-right of a 4×4 grid should be `(3, 3)`. Then answer a few:

- What's the bottom-left corner's coordinate?
- If the robot is at `(1, 2)`, what's directly below it? Directly right?
- From `(0, 0)` to `(3, 2)`: how many rows, how many columns, how many total steps?

<KnowledgeCheck
  question="The robot is at (1, 2). What position is directly below it (one row down)?"
  options={[
    {text: '(1, 3)'},
    {text: '(2, 2)', correct: true},
    {text: '(0, 2)'},
    {text: '(2, 3)'},
  ]}
  explanation="Moving down increases the row by 1 and leaves the column alone: (1, 2) → (2, 2)."
/>

<TeacherNote title="Differentiation">

**More support:** start on a 3×3 grid; color-code each row; hand out a
partially-filled grid to complete. **More challenge:** an 8×8 grid; "how many
intersections on an N×N grid?" (N×N); and the combinatorics teaser — how many
*different* shortest paths exist from `(0,0)` to `(2,3)`? Note there are many equal-
length paths; the Manhattan algorithm will pick one specific route (rows first, then
columns).

</TeacherNote>

## Wrap-up

- Which number comes first, and what does it mean? (Row — how far down.)
- Why start counting at 0? (To match how Python indexes, avoiding confusion later.)
- How do you find the number of steps between two spots? (Row difference + column difference.)
