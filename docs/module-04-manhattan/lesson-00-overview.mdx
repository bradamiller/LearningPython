## The whole program — really

Here's the *entire* main program you're building toward. Seven lines:

```python
manhattan = Manhattan((0, 0))
navigator = Navigator((0, 0), 0)
destinations = [(2, 0), (2, 3), (0, 3)]

for dest in destinations:
    path = manhattan.compute_path(dest)
    navigator.drive_path(path)
    manhattan.position = navigator.position
```

In plain English: *make a planner and a driver, both starting at corner (0, 0); for
each destination, compute the path, drive it, and update where we are.* You don't
need to understand `compute_path` or `drive_path` yet — just see that the program is
short **because the classes do all the work**.

(Those seven lines are the *interesting* part. The real program also opens with the
class definitions and the `board.wait_for_button()` that every robot program starts
with — they're left out here so the shape stands out.)

## Two classes, two jobs

<CardGrid>
  <InfoCard tag="Planner" title="Manhattan">
    Given where you are and where you want to go, it computes a <strong>list of intersections</strong> to follow. It never touches the robot.
  </InfoCard>
  <InfoCard tag="Driver" title="Navigator">
    Given that list, it <strong>drives the robot</strong> through each intersection — turning and line-following. It never decides the route.
  </InfoCard>
</CardGrid>

`Manhattan` produces a path; `Navigator` consumes it. Each class has exactly one
responsibility — that's called **separation of concerns**, and it makes bugs easy to
find: a wrong route is a `Manhattan` problem; a wrong turn is a `Navigator` problem.

## Your roadmap

Every lesson in this module builds one piece of that program:

- **Lesson 4-1** — coordinates: the `(row, col)` system
- **Lesson 4-2** — tuples: storing a position like `(2, 3)`
- **Lesson 4-3** — lists: storing a path like `[(1,0), (2,0), (3,0)]`
- **Lessons 4-4 and 4-5** — the Manhattan algorithm: computing paths (on paper, then in code)
- **Lesson 4-6** — testing your code without a robot
- **Lesson 4-7** — turning logic: headings as numbers
- **Lesson 4-8** — the `Navigator` class, built on your Module 2 `LineTrack`
- **Lesson 4-9** — the final project: it all comes together

Notice `Navigator` reuses `LineTrack` from Module 2 for the actual driving — you're
not starting from scratch. That's the payoff of building reusable classes.
