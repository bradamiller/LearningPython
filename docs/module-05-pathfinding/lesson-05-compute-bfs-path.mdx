```python
def bfs_distances(destination):
    """Steps from every reachable intersection to
    destination, as a dictionary: the wave of numbers."""
    # Program only, not a step of the algorithm: build the
    # graph from BLOCKED; return {} if destination is not in it.
    #
    # Number the grid from the destination (Lesson 5-2):
    #  1. Write 0 on the destination.
    #  2. Put the destination on the to-visit list.
    #  3. While the to-visit list is not empty:
    #  4.     Take the oldest one off the front. Call it current.
    #  5.     For each open neighbor of current:
    #  6.         If that neighbor has no number yet:
    #  7.             Give it one more than current's number.
    #  8.             Add it to the end of the to-visit list.
    #  9. Return the numbers.
    pass

def compute_bfs_path(start, destination):
    """Shortest path from start to destination around
    BLOCKED, as the list of intersections to drive to."""
    # Program only: build the graph from BLOCKED.
    #
    # Walk downhill from the start (Lesson 5-2):
    #  1. Number the grid: call bfs_distances(destination).
    #  2. If the start has no number, there is no path.
    #  3. Start with an empty path, standing on the start.
    #  4. Until you are standing on the destination:
    #  5.     Find the open neighbor whose number is one less
    #  6.     and step onto it.
    #  7.     Add where you are standing to the path.
    #  8. That path is the answer.
    pass

def print_grid(rows, cols, blocked, numbers):
    """Draw the grid the way it lies in front of you: the top
    line is the far row, y = 0 is the bottom line. Each
    intersection shows its entry in numbers, X if it is
    blocked, . if it has no entry."""
    for i in range(rows):
        y = rows - 1 - i
        line = " " + str(y) + " | "
        for x in range(cols):
            if (x, y) in blocked:
                cell = "X"
            elif (x, y) in numbers:
                cell = numbers[(x, y)]
            else:
                cell = "."
            line = line + "{:>3}".format(cell)
        print(line)
    print("    " + "-" * (3 * cols + 1))
    footer = "     "
    for x in range(cols):
        footer = footer + "{:>3}".format(x)
    print(footer)
```

`print_grid()` is given: it's formatting, not pathfinding, and Module 6 uses it
unchanged. It prints the far row first, so the picture lies the way the grid does in
front of you. `"{:>3}".format(cell)` is "this value, right-aligned in three spaces."

## Every line is a pencil step

Under each numbered comment you write the Python that does what the step says, usually
one line. Use the names from Lesson 5-3: `distance` for the numbers, a dictionary, and
`to_visit` for the list. Step 1 of `bfs_distances()` makes `distance` with one entry: the
destination, numbered 0.

<Figure
  src="/img/lesson-m5-05/code-pencil-downhill.svg"
  alt="Eight lines of code matched to the pencil method from Lessons 5-1 and 5-2. distance = {destination: 0} writes 0 on the destination. to_visit = [destination] is the to-visit list beside the grid. current = to_visit.pop(0) takes the oldest one, from the front. if neighbor not in distance means it has no number yet, so it is numbered once. distance[neighbor] = distance[current] + 1 gives it one more than current. to_visit.append(neighbor) adds it to the end of the list. while current != destination walks until it reaches the destination, and distance[neighbor] == distance[current] - 1 finds a neighbor one less to step onto."
  caption="Nothing in the code is new: each line is a step you already did with a pencil."
/>

An intersection gets an entry in `distance` only when the wave reaches it, so "is a key in
`distance`" means "has a number." That's why `if neighbor not in distance` is the whole
numbered-once rule.

The list is a **queue**: `append()` adds to the end and `pop(0)` takes from the front
(index 0), so the wave front moves out one step at a time.

### Step 2 · The walk downhill

Write `compute_bfs_path()`. If the start has no number, the wave never reached it, so
there's no path; that one check covers a blocked start, a blocked destination and a wall
between them.

Steps 4 to 7 are a loop inside a loop. The outer `while` keeps walking until you're on the
destination. The inner `for` looks through the neighbors for one with a number one less;
when it finds one, it steps onto it and uses `break` to stop looking. Check that the
neighbor has a number before you compare it: `neighbor in distance and ...`. And notice
when the start is left out: you add an intersection to the path only *after* stepping onto
it, so the start never goes in, and "already there" comes free: when `start == destination`,
the loop never runs and the path is `[]`.

```python
def bfs_distances(destination):
    """Steps from every reachable intersection to
    destination, as a dictionary: the wave of numbers."""
    graph = build_graph(ROWS, COLS, BLOCKED)
    if destination not in graph:
        return {}
    distance = {destination: 0}
    to_visit = [destination]
    while len(to_visit) > 0:
        current = to_visit.pop(0)
        for neighbor in graph[current]:
            if neighbor not in distance:
                distance[neighbor] = distance[current] + 1
                to_visit.append(neighbor)
    return distance

def compute_bfs_path(start, destination):
    """Shortest path from start to destination around
    BLOCKED, as the list of intersections to drive to."""
    graph = build_graph(ROWS, COLS, BLOCKED)
    distance = bfs_distances(destination)
    if start not in distance:
        return []
    path = []
    current = start
    while current != destination:
        for neighbor in graph[current]:
            if neighbor in distance and distance[neighbor] == distance[current] - 1:
                current = neighbor
                break
        path.append(current)
    return path
```

## Activity · Break it on purpose

Once all five pass, break `bfs_distances()` two ways. Put each back before the next.

1. **Change `pop(0)` to `pop()`.** Run Test 4 and count the steps: more. `pop()` takes
   the *newest* intersection, so the wave no longer moves out one step at a time and the

   yours.

   empties and the program hangs. Press Ctrl-C. That one line is the numbered-once rule.

```python
# ===== BFS PLANNER =====
# The second planner. compute_bfs_path(start, destination)
# has the same shape as the MANHATTAN PLANNER's function and
# keeps the same two promises (told the position; the path
# leaves the start out). bfs_distances() numbers the GRID GRAPH
# as a wave from the destination; the path walks downhill from
# the start, so it routes AROUND whatever is in BLOCKED. Pure
# dictionary work: every test here runs with the robot still.

def bfs_distances(destination):
    """Steps from every reachable intersection to
    destination, as a dictionary: the wave of numbers."""
    graph = build_graph(ROWS, COLS, BLOCKED)
    if destination not in graph:
        return {}
    distance = {destination: 0}
    to_visit = [destination]
    while len(to_visit) > 0:
        current = to_visit.pop(0)
        for neighbor in graph[current]:
            if neighbor not in distance:
                distance[neighbor] = distance[current] + 1
                to_visit.append(neighbor)
    return distance

def compute_bfs_path(start, destination):
    """Shortest path from start to destination around
    BLOCKED, as the list of intersections to drive to."""
    graph = build_graph(ROWS, COLS, BLOCKED)
    distance = bfs_distances(destination)
    if start not in distance:
        return []
    path = []
    current = start
    while current != destination:
        for neighbor in graph[current]:
            if neighbor in distance and distance[neighbor] == distance[current] - 1:
                current = neighbor
                break
        path.append(current)
    return path

def print_grid(rows, cols, blocked, numbers):
    """Draw the grid the way it lies in front of you: the top
    line is the far row, y = 0 is the bottom line. Each
    intersection shows its entry in numbers, X if it is
    blocked, . if it has no entry."""
    for i in range(rows):
        y = rows - 1 - i
        line = " " + str(y) + " | "
        for x in range(cols):
            if (x, y) in blocked:
                cell = "X"
            elif (x, y) in numbers:
                cell = numbers[(x, y)]
            else:
                cell = "."
            line = line + "{:>3}".format(cell)
        print(line)
    print("    " + "-" * (3 * cols + 1))
    footer = "     "
    for x in range(cols):
        footer = footer + "{:>3}".format(x)
    print(footer)

def test_distances():
    clear_blocked()
    add_blocked((1, 0))
    add_blocked((1, 1))
    print("=== Distances to (3,0) with (1,0) and (1,1) blocked ===")
    print_grid(ROWS, COLS, BLOCKED, bfs_distances((3, 0)))

def test_bfs_open():
    clear_blocked()
    for (start, dest, expect) in [((0, 0), (3, 3), 6),
                                  ((0, 0), (0, 3), 3),
                                  ((2, 2), (2, 2), 0)]:
        path = compute_bfs_path(start, dest)
        print("===", start, "to", dest, "===")
        print("Path:", path)
        print("Steps:", len(path), "(expect", expect, ")")

def test_bfs_walls():
    clear_blocked()
    add_blocked((1, 0))
    add_blocked((1, 1))
    print("=== wall across the grid, (0,0) to (3,0) ===")
    print("Blocked:", BLOCKED)
    path = compute_bfs_path((0, 0), (3, 0))
    print("Path:", path)
    print("Steps:", len(path), "(expect 7 -- around the wall)")
    add_blocked((1, 2))
    add_blocked((1, 3))
    print("=== destination walled off ===")
    print("Blocked:", BLOCKED)
    path = compute_bfs_path((0, 0), (3, 0))
    print("Path:", path)
    print("Steps:", len(path), "(expect 0 -- no way through)")

# ===== RUN =====
board.wait_for_button()
test_bfs_walls()
```

`test_bfs_open()` loops over three tuples; three separate print blocks are just as
good and are what most students will write. `compute_bfs_path()` builds the graph itself
as well as calling `bfs_distances()`, because the walk needs each intersection's open
neighbors.
