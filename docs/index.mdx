Students progress from visual block-based programming all the way to autonomous
grid navigation with obstacle avoidance — writing real Python to make an XRP
robot drive, sense, and think. Every concept is introduced right when it's
needed to solve a concrete robot problem.

## The modules

<CardGrid>
  <InfoCard tag="Module 1" title="Learning to Drive" href="/module-01-driving/lesson-00-what-is-a-robot">
    Visual programming → Python. Variables, loops, functions, and the XRP API.
  </InfoCard>
  <InfoCard tag="Module 2" title="Line Tracking" href="/module-02-line-tracking/lesson-01-reflectance-sensor">
    Sensors and control loops. While loops, conditionals, and the line-sensor functions you build on all course.
  </InfoCard>
  <InfoCard tag="Module 3" title="Grid Driving" href="/module-03-grid-driving/lesson-01-introduction-to-the-grid">
    Using your own line-tracking functions to drive patterns on a real taped grid.
  </InfoCard>
  <InfoCard tag="Module 4" title="Manhattan Navigation" href="/module-04-manhattan/lesson-00-overview">
    Coordinate systems, tuples and lists, and algorithmic pathfinding.
  </InfoCard>
  <InfoCard tag="Module 5" title="Pathfinding Around Obstacles" href="/module-05-pathfinding/lesson-01-grid-as-a-graph">
    Graphs, breadth-first search, obstacle detection, and dynamic rerouting in real time.
  </InfoCard>
  <InfoCard tag="Module 6 · optional" title="Dijkstra's Algorithm" href="/module-06-dijkstra/lesson-00-overview">
    The same algorithm with one upgrade, for grids where some segments are slower than others.
  </InfoCard>
</CardGrid>
