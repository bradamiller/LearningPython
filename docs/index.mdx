Students progress from visual block-based programming all the way to autonomous
grid navigation with obstacle avoidance — writing real Python to make an XRP
robot drive, sense, and think. Every concept is introduced right when it's
needed to solve a concrete robot problem.

## The five modules

<CardGrid>
  <InfoCard tag="Module 1" title="Learning to Drive">
    Visual programming → Python. Variables, loops, functions, and the XRP API.
  </InfoCard>
  <InfoCard tag="Module 2" title="Line Tracking">
    Sensors and control loops. While-loops, conditionals, and your first classes.
  </InfoCard>
  <InfoCard tag="Module 3" title="Grid Driving">
    Applying your own classes to drive patterns on a real taped grid.
  </InfoCard>
  <InfoCard tag="Module 4" title="Manhattan Navigation">
    Coordinate systems, tuples and lists, and algorithmic pathfinding.
  </InfoCard>
  <InfoCard tag="Module 5" title="Dijkstra's Algorithm">
    Graphs, obstacle detection, and dynamic rerouting in real time.
  </InfoCard>
</CardGrid>
