## The mission

Make the robot drive a square: each side is 2 intersections, with a right turn at
each of the 4 corners. Done right, it finishes where it began.

<Figure
  placeholderLabel="Diagram — grid with a square path, 2 segments per side, right turn at each corner, start = end"

/>

**Your program must:** use the `LineTrack` class, drive the square with a `for` loop
(not four copied blocks), print progress, and return to start.

## One loop, four sides

The whole square is a four-iteration loop. Each pass drives one side, then turns the
corner:

```python
# (LineSensor and LineTrack classes from Module 2 go above)

def drive_intersections(tracker, count):
    for i in range(count):
        tracker.track_until_cross()
        if i < count - 1:
            tracker.drivetrain.set_effort(0.3, 0.3)
            time.sleep(0.3)

board = Board.get_default_board()
tracker = LineTrack()

board.wait_for_button()
print("Module 3 Final Project — Square Pattern!")

sides = 2                     # intersections per side

for leg in range(4):
    print("Side", leg + 1, "of 4")
    drive_intersections(tracker, sides)
    print("  Turning right...")
    tracker.turn_right()

print("Square complete! Back at start.")
```

Notice there's no separate clear before `turn_right()` — the turn clears the corner
itself (Lesson 3). Four right turns add up to a full 360°, which is why the robot
comes back around.

## Activity · Test one side at a time

Don't run all four sides first. Build up:

1. **One side** — comment out the loop; run one `drive_intersections(2)` + `turn_right()`.
2. **Two sides** — `range(2)`; you should get an L (half the square).
3. **Full square** — `range(4)`; does it close back to the start?

<TeacherNote title="Run it as a build; tuning is the lesson">

Treat this as plan → build → test → present, and insist on **incremental testing** —
one side, then two, then four. The common fixes are all tuning: turns that aren't
quite 90° (the square drifts open), a clear time that skips or overshoots, or too
much `base_effort`. Frame that as real engineering. Returning *approximately* to
start is success; a perfectly closed square on real tape is a bonus. Two clean sides
already show mastery of the concept.

</TeacherNote>
