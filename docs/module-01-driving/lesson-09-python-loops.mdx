Remember the **Repeat** block that made shapes so much shorter? Python has the
same tool: the **`for` loop**. In this lesson you'll write loops in text and use
them to draw the shapes you already know — proving the logic is identical, only
the syntax changed.

- Use the loop counter (`i`) to print progress or change behavior each pass

</Objectives>

## Part 1 · The Repeat block, in text

Here's the square you drew in Lesson 2 as a Blockly Repeat — and the Python `for`
loop that does the same thing:

<BlockProgram
  blocks={[
    {name: 'repeat', note: 'repeat 4 times', children: [
      {name: 'straight', note: 'cm: 30'},
      {name: 'turn', note: 'Deg: 90'},
    ]},
  ]}
/>

```python
for i in range(4):
    drivetrain.straight(30)
    drivetrain.turn(90)
```

Breaking down that first line:

- `for` — the keyword that starts a loop.
- `i` — a counter variable (you can use it or ignore it).
- `range(4)` — produces the numbers `0, 1, 2, 3` — four of them.
- `:` — required, and everything **indented** under it is the loop body.

<KnowledgeCheck
  question="What numbers does range(4) produce?"
  options={[
    {text: '1, 2, 3, 4'},
    {text: '0, 1, 2, 3', correct: true},
    {text: '0, 1, 2, 3, 4'},
    {text: '4, 3, 2, 1'},
  ]}
  explanation="range(n) counts from 0 and stops BEFORE n, so range(4) is 0, 1, 2, 3 — four numbers, which is why the loop runs 4 times."
/>

<TeacherNote title="Two predictable stumbles">

Two things trip nearly everyone: (1) **counting from 0** — `range(4)` is
`0,1,2,3`, not `1,2,3,4`; and (2) **indentation as syntax** — the indented lines
are the loop body, and getting the spaces wrong is an actual error, not a style
nitpick. Demonstrate both the broken (un-indented) and correct versions so they
see the error message.

</TeacherNote>

## Part 2 · Indentation decides what repeats

Indentation isn't decoration — it's how Python knows which lines are inside the
loop. Compare:

```python
for i in range(4):
    drivetrain.straight(30)
    drivetrain.turn(90)
print("Square complete!")     # NOT indented → runs once, after the loop
```

The two indented lines repeat four times; the `print` runs once at the end because
it's not indented.

## Part 3 · Use the counter

The loop variable isn't just for counting — you can *use* it. This prints which
side it's drawing as it goes:

```python
for i in range(5):
    print(f"Drawing side {i + 1} of 5")
    drivetrain.straight(20)
    drivetrain.turn(72)
```

The `f"…{i + 1}…"` is an **f-string** — it drops the value of `i + 1` right into
the text. We use `i + 1` so the messages read "1, 2, 3…" instead of "0, 1, 2…".
